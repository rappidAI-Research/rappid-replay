# Security reporting

Email [cikemgil@rappidai-research.com](mailto:cikemgil@rappidai-research.com)
with the affected revision, impact and a minimal reproduction. Remove secrets,
private source and sensitive recordings before sharing. Do not publish
sensitive vulnerability details in an issue. No response time is guaranteed.

Replay records commands, workspace state and outputs. Encryption at rest does
not remove sensitive content from a capture. Verify restored state before use;
a live rerun executes code and can reconnect to external services. Replay does
not guarantee identical outcomes or record all external inputs.
